# Established Boss Pack - 13 Bosses

This review-only native export contains the 13 established bosses. The unapproved fourteenth candidate is intentionally excluded.

Each `bosses/<id>/` folder contains 96 PNGs:

- one 960x192 full animation sheet;
- four 960x48 direction animation sheets;
- six scoped animation sheets;
- eighty individual 48x48 animation frames;
- one 48x192 static direction sheet;
- four individual 48x48 static direction frames;
- one per-boss JSON manifest.

All PNGs are native 1x with hard alpha. The root manifest records the roster, animation contract, dimensions, and file counts.
