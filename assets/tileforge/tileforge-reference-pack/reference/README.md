# TileForge sprite-reference pack

**You are probably an AI agent building a sprite forge.** This folder is your
complete, self-contained briefing on the world your sprites must live in. It was
generated by TileForge — a deterministic 32×32 tile compiler whose output feeds
top-down games (first consumer: a bullet-hell open-world Godot game). You do not
need TileForge, its repo, or any other context to use this pack.

## The contract

- TileForge owns the WORLD: terrain, props, structures, decals, crops, networks.
- Your forge owns the ACTORS: player, enemies, NPCs, projectiles, effects.
- This pack is the only artifact that crosses the boundary. If it goes stale
  (the tileset evolves), ask for a regenerated pack — never for tile changes.

## Read in this order

1. **This file** — orientation.
2. **SPRITE-REFERENCE.md** — the world's visual laws (light, outline, shadow,
   contrast doctrine, theme system, animation cadence, scale). Sprites that
   break these laws will look pasted-on. This is the most important document.
3. **manifest.json** — machine-readable inventory: every scene and flagship
   with its size, biome, contents and file paths, plus palette/regeneration
   metadata. Parse this rather than globbing filenames.
4. **viewer.html** — open in any browser for one-click visual browsing
   (theme filter buttons included).

## What the images are

- `scenes/` — 13 focused biome scenes ×4 themes. `*-1x.png` files are GROUND
  TRUTH (1 tile = 32px). Scale only by nearest-neighbor. `scale-lineup` is the
  height ladder for calibrating actor sizes (~22–30 px tall in a cell).
- `flagships/` — three large composed worlds (walled mountain city, harbor
  town, dark wilds) — the busiest realistic settings your sprites will face.
  **Judge every sprite candidate composited over these at 1× and 2×.** If it
  reads there — silhouette clear, no camouflage, right scale — it works in the
  game.
- `palette.json` + `palette-*.png` — every color the world uses, per theme.
  `materialBaseHex` is your camouflage checklist: keep actor silhouette values
  ~15+ luma away from any ground the actor can walk on.
- `animation-cadence.png` — the world's 4-frame ~300 ms animation rhythm.

## Provenance

Generated 2026-07-25; images refreshed 2026-07-26 on the RD7 engine
(31,431 tiles/theme, validation clean, engine commit `199ed7d`) with routes
re-authored to the post-RD7 road doctrine (REFROADS: bare packedroad
corridors for routes, dirtpath bands as trails only, town streets as cobble
areas — the net16 road band is retired from display). Rendered on the exact
export path the game consumes (frame 0). Deterministic: the same commit
regenerates byte-identical images (`cli/reference-scenes.mjs`,
`cli/flagship-maps.mjs` in the TileForge repo).
